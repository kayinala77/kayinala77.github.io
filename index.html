Ayinala Portfolio Contribution

Equity traders face the challenge of turning raw price data into clear BUY, SELL, or HOLD signals. To solve this, I built an end-to-end Python system that fetches historical and real-time data via Yahooquery, computes the Gann Hi-Lo Activator indicator (raw and EMA-smoothed), and then orchestrates a specialized CrewAI “Gann Investment Advisor” agent—powered by GPT-4o with a defined role, goal, and backstory—to analyze the latest indicator values alongside current market prices. The agent’s recommendations are assembled by a Crew orchestrator, displayed in a Streamlit dashboard for live decision support, and validated through a Backtrader backtesting framework that outputs equity curves and performance metrics. All code is public on GitHub.
